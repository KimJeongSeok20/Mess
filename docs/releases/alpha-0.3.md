# MessUp Alpha 0.3

게임 버전 `0.3.0` · Windows 64-bit

## 변경 내용

- 몬스터 처치 시 수집하면 스킬 포인트를 주는 orb가 나옵니다. 시체 분쇄기도 기존 아이템 드롭과 즉시 포인트 지급 대신 orb만 배출합니다.
- 분쇄기의 높은 배출구에서 orb가 나와 바닥에 내려옵니다. 분쇄음 시작 약 1초 뒤 피가 연속 분출하며, orb 착지 지점에 웅덩이가 남습니다. 별도로 피 방울이 계속 떨어지는 효과는 제거했습니다.
- Clown 시체의 인벤토리 아이콘, 손에 든 머리 모델, 버리기와 재픽업 경로를 연결했습니다.
- 모루 강화 화면과 스타 캐치, 강화 화면 사용 중 입력 차단, 몬스터 명중음 및 하루 시작 시 체력 회복 등 현재 프로젝트 변경 사항을 반영했습니다.

## 설치

1. [Alpha 0.3 릴리스](https://github.com/KimJeongSeok20/MessUp/releases/tag/alpha-0.3)에서 모든 `tar.part` 파일과 `README_RELEASE.txt`, `SHA256SUMS.txt`로 끝나는 파일을 같은 폴더에 받습니다.
2. `README_RELEASE.txt`의 명령으로 조각을 합치고 압축을 풉니다.
3. 새 폴더의 `MessUP.exe`를 실행합니다. 로컬 플레이는 Steam 없이 실행할 수 있습니다.

## 확인 범위

Editor 호스트에서 시체 픽업, Clown 손 모델·아이콘, 버리기·재픽업, 중복 처리 방지, orb 수집 보상, 분쇄 효과 지연과 웅덩이 위치를 확인했습니다. 이번 배포에서 실제 두 계정의 Steam 멀티플레이는 재검증하지 않았습니다.

Windows 64-bit 배포 빌드는 오류 0개로 완료했습니다. 독립 실행에서 로컬 이어하기, 플레이어 1명 생성, 입력 활성화와 기존 세이브 보존을 확인했습니다.

**알려진 검증 제한:** 자동 실행 검사 두 차례 모두 타이틀 복귀의 30초 제한을 초과했습니다. 단독 재실행에서는 이어하기가 약 23.9초에 준비됐고, 타이틀 씬 로드는 약 30.7초에 완료됐습니다. 전체 자동 검사는 실패로 기록했으며, 뒤따르는 새 게임 재진입 검사는 실행되지 않았습니다. 로딩 시간은 실행 환경에 따라 달라질 수 있습니다.

공개 저장소는 C# 소스 스냅샷입니다. 파일별 해시와 전체 프로젝트의 로컬 커밋은 `SOURCE_SNAPSHOT.json`에 기록합니다. 실행 파일은 GitHub 릴리스에서 받습니다.
