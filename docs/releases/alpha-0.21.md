# Alpha 0.21

Windows 64-bit 빌드입니다. 게임 내부 버전은 `0.21.0`입니다.

## 변경 내용

- 메인 메뉴에 Steam 접속 없이 혼자 플레이하는 `LOCAL PLAY`와 로컬 저장 이어하기를 추가했습니다.
- 시작 버튼 이후 캠프 진입 시 던전 전체의 조명 데이터를 함께 읽던 경로를 분리했습니다. 로딩 상태를 표시하고 일반 텍스처에 스트리밍을 적용했습니다.
- 등록된 던전이 하나일 때는 캠프 진입 후 해당 맵을 미리 읽습니다. 여러 맵을 등록하면 선택된 맵만 읽고, 맵 교체 시 이전 맵의 참조와 조명 캐시를 정리합니다.
- 던전 준비가 끝난 뒤 게임 내 시간과 배터리 소모를 시작하도록 했습니다. 기존 던전 생성, 전리품, 방 회전과 전원 상태별 조명 데이터는 유지했습니다.

## 설치 및 실행

1. [Alpha 0.21 릴리스](https://github.com/KimJeongSeok20/MessUp/releases/tag/alpha-0.21)에서 `tar.part001`부터 마지막 조각까지, `README_RELEASE.txt`, `SHA256SUMS.txt`로 끝나는 파일을 같은 폴더에 받습니다.
2. `README_RELEASE.txt`의 명령으로 조각을 합치고 압축을 풉니다. 각 조각은 따로 열 수 없습니다.
3. `MessUP-win64-alpha0.21/MessUP.exe`를 실행합니다. 혼자 플레이할 때는 `LOCAL PLAY`를 선택합니다.

## 확인 범위

로컬 이어하기, 새 게임, 타이틀 복귀, 입력 활성화와 기존 사용자 저장 보존을 확인했습니다. 같은 게임 코드의 스탠드얼론 검증에서 두 시드의 던전 생성과 실제 입장, 다음 날 재생성, 방 회전·전원 상태별 조명 연결, 캠프 조명 복원을 확인했습니다. 두 개의 테스트 맵을 이용한 선택 로딩 및 잘못된 맵 거부 회귀 검사 7개도 통과했습니다.

첫 던전에 즉시 들어가면 아직 읽고 있는 맵 데이터를 기다릴 수 있습니다. 로딩 시간은 디스크와 캐시 상태에 따라 달라집니다. 실제 두 계정의 Steam 멀티플레이와 모든 방·전원 조합의 화면 비교는 이번 릴리스에서 재검증하지 않았습니다.

이 저장소는 공개 가능한 C# 소스 스냅샷이며, 실행에 필요한 게임 파일은 릴리스에 있습니다. 소스 파일별 해시는 저장소 루트의 `SOURCE_SNAPSHOT.json`에 기록되어 있습니다.
