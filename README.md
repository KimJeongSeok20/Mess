## 이 저장소에 대하여

**코드 리뷰용 저장소입니다. 클론해도 빌드되지 않습니다.**

에셋스토어에서 구매한 모델·사운드·에디터 확장이 프로젝트의 상당 부분을 차지하는데, 라이선스상 재배포할 수 없어 제외했습니다. 씬·프리팹·머티리얼도 함께 빠졌습니다. 이 저장소에는 **직접 작성한 C# 스크립트 473개**만 들어 있습니다.

실제로 플레이해보시려면 Releases의 빌드를 받아주세요.

## 게임 소개

리썰 컴퍼니 계열의 협동 루팅 게임입니다. 하루가 실시간 10분(게임 내 9:00~24:00) 동안 흐르고, 그 안에서 아래 루프를 반복합니다.

1. **하루 시작** — 시계를 홀드하면 서버가 시드를 뽑아 던전을 생성합니다
2. **탐색과 루팅** — 어두운 던전을 돌며 아이템을 회수합니다. 밤이 되면 몬스터 스폰 간격이 45초에서 2초로 좁혀집니다
3. **판매** — 회수한 아이템을 포장해 우편함에 넣으면 공유 자금으로 환산됩니다
4. **세금** — 3일마다 할당량이 청구되고, 사이클마다 1.3배씩 오릅니다. 유예일이 지나도 미납이면 **퇴거** — 자금이 0이 되고 1일차부터 다시 시작합니다

여기에 무기 강화(모루), 스킬 트리, 상점, 가방 확장, 구역별 전원 차단 시스템이 붙습니다.

## 주요 구현

### 절차적 던전의 베이크 조명 파이프라인

가장 오래 붙잡은 문제입니다. 던전이 런타임에 조립되기 때문에 조명을 미리 구울 수가 없고, 그렇다고 전부 실시간으로 돌리면 프레임이 나오지 않습니다.

타일 단위로 라이트맵을 미리 굽고 런타임에 조립하는 방식을 택했고, 그 과정에서 인접 방 사이의 빛 누출·포털 너머 조명 전달·구역 전원 상태(P0/P100)별 라이트맵 교체를 각각 PoC로 검증했습니다. `Assets/Experiments` 아래 네 갈래로 남아 있습니다.

### 서버 권한 이전

초기에는 인벤토리·거래·부활 처리를 클라이언트가 결정하고 서버에 통보하는 구조였습니다. 아이템 소유권 검증, 거래·드롭·유료 부활의 서버 측 확인, 클라이언트 요청 차단을 순차적으로 옮겼습니다. 현재 30개 스크립트에서 ServerRpc로 상태 변경을 서버에 위임합니다.

### 몬스터 AI

비헤이비어 그래프 기반으로 몬스터 3종을 구현했습니다. Clown은 타깃 획득 → 접근 → 선물 투척 시퀀스를, smily는 순찰과 추격을 담당합니다. 사망 시 시체를 남기는 파이프라인(`CorpseProcessor`)을 공유합니다.

### 에디터 자동화

라이트맵 베이크, 프리팹 셋업, 문 개구부 검증을 에디터 툴로 자동화했습니다. 79개 스크립트 중 상당수가 회귀 테스트로, 전투·사망·인벤토리 계약이 깨지지 않는지 확인합니다.
